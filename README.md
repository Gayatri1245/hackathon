# HackSpire Hackathon Submission - Personal Portfolio

A simple HTML & CSS portfolio website submitted for the HackSpire Hackathon to receive a participation certificate.

## Project Structure

```
hackathon/
├── index.html    # Main HTML file
├── style.css     # CSS stylesheet
└── README.md     # This file
```

## How to Use

1. **Customize the Portfolio:**
   - Open `index.html` in a text editor
   - Replace "Your Name" with your actual name
   - Update the email, location, and social links in the contact section

2. **View the Website:**
   - Double-click `index.html` to open it in your browser
   - Or drag the file into a web browser

3. **Submit to Hackathon:**
   - Zip the entire folder (index.html + style.css)
   - Go to: https://devpost.com/submit-to/29885-hackspire-hackathon/manage/submissions
   - Upload the zip file as your submission

## Customization Tips

To make this portfolio your own:

1. **Change your name:**
   ```html
   <h1>Hello, I'm <span class="highlight">Your Name</span></h1>
   ```

2. **Update contact info:**
   ```html
   <span class="contact-value">your.email@example.com</span>
   ```

3. **Change colors in style.css:**
   ```css
   :root {
       --primary-color: #2563eb;  /* Change this color */
       --secondary-color: #1e40af;
   }
   ```

4. **Add your social links:**
   ```html
   <a href="https://github.com/yourusername" class="social-link">GitHub</a>
   ```
